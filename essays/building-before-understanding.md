Before taking ICS 314, I had already encountered TypeScript in a few projects, mostly through vibe-coding and other hobby work. I'd used it as part of larger projects, but without much understanding of what TypeScript itself was doing. Over the summer, I experimented heavily with Claude and used it to build websites involving tools such as GitHub, Cloudflare, Astro, and TypeScript. That let me work with technologies I probably wouldn't have reached on my own yet, but it also made me realize that being able to build something is different from understanding how it works.

This module has started filling in some of those gaps. I had already seen features such as let, const, classes, arrays, and for...of in generated code, but I hadn't always stopped to understand why they were being used. Learning TypeScript directly has made me think more about types, functions, classes, and other language features instead of letting an LLM handle them for me. From a software engineering perspective, I think TypeScript is useful because its type system makes expectations clearer and can catch certain mistakes before a program runs. The additional syntax can feel unnecessary in a small exercise, but I can see why it becomes more useful as a project grows.

The practice WODs have probably exposed my lack of fluency more clearly than anything else. In a way, they put my ego in check. I can work on a website using several technologies with AI assistance, but a timed programming problem can still make me stop and think about loops, syntax, or how to approach the problem. I find the WODs stressful because I've never really programmed under this kind of time constraint, and I'm not particularly good at thinking on the spot. At the same time, that's part of why I think they're useful. They make it harder to avoid the areas where I still need practice.

I don't know if athletic software engineering is the best learning style for me, but I want to give it a fair chance. I'd like the WODs to become less uncomfortable as the semester goes on and as basic programming patterns become more automatic. My goal is less about performing well on every WOD and more about finishing the semester with stronger fundamentals than I started with. AI has already shown me how quickly I can build with assistance; what I need now is the ability to better understand, evaluate, and eventually write more of that code myself.
